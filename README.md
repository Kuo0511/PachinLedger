# Pachi Ledger v3 — Pachinko / Pachislot 紀錄 PWA

## 在 VS Code 使用
1. 以 VS Code 開啟 `pachinko-tracker` 資料夾。
2. 安裝 Live Server 擴充套件，在 `index.html` 點選 **Open with Live Server**；或以 `python3 -m http.server 8000` 開啟伺服器。
3. 前往 `http://localhost:8000`；PWA 安裝需 HTTPS 或 localhost。

## v3 新功能
- 移除換金率。持玉投入與出玉統一用「投入換算」估值，預設 1 日圓／玉（枚）。
- 現金投入、回收欄位上下調整步進值 100 日圓；可在欄位直接輸入其他非負整數，以相容歷史金額。
- 機台機率選填，格式 `1/99`、`1/179` 等。
- 店家與機台名稱選填；缺少名稱會顯示「未填店家／未填機台」。
- 專案管理：新增專案，紀錄可選專案，紀錄清單及分析可依專案篩選，查看專案別損益統計。刪除專案不會刪遊玩紀錄。
- 舊版 v1/v2 紀錄與 JSON 備份可匯入，匯出為 v3（含專案）。

## 計算方式
`損益 = 現金回收 + 出玉 × 投入換算 − 現金投入 − 持玉投入 × 投入換算`

貯玉、提領與期初庫存另外追蹤，不重複計入遊玩損益。投入換算為記帳估值，**不是實際換金率**。

## 資料保存
資料存於目前瀏覽器 localStorage；更換網域、瀏覽器或裝置不會自動同步。匯出 JSON 定期備份。
更新時建議先於舊版匯出備份；v3 沿用既有紀錄儲存鍵，可在同一網域讀取既有資料。
